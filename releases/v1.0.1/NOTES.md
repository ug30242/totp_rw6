첨부 소스를 정리한 첫 공개 수정 릴리스입니다. 대상: 중국판 Redmi Watch 6, 사용자 보고 펌웨어 3.100.043, Notify for Xiaomi.

설치 파일: **com.vela.rw6totp.release.1.0.1.rpk**. Notify의 **펌웨어 업데이트 → 타사 앱(RPK)**에서 이 파일을 직접 선택하세요.

- 첨부 원본 RPK의 서명 콘텐츠 해시 불일치 재현 및 공식 aiot-toolkit 2.0.5 재빌드로 수정
- 외부·내부 RSA 서명, 패키지·파일 해시와 CRC 검증 및 기존 서명 인증서 유지
- 잘못된 OTP 설정·암호화 패킷 거부, 저장 실패 시 기존 데이터 보존, 중복 등록·동시 저장 보호
- 삭제 확인, 오류 표시, OTP 계산 캐시, 등록 세션 만료와 오래된 응답 무시
- 외부 스크립트가 없는 독립 웹 등록 도구 추가 (`totp-import.html`)
- 표준 RFC OTP 벡터, 데이터 보존·세션·패키지 회귀 테스트 및 Chromium 웹 동작 테스트

**실기기 설치는 아직 검증하지 못했습니다.** 패키지 결함은 수정·검증했으나 Notify의 파일 인식과 BLE 전송, 펌웨어 3.100.043의 설치 정책은 재확인이 필요합니다. 실패하면 Notify의 정확한 버전과 로그를 알려 주세요. 관련 절차는 저장소의 `docs/notify-installation.md`에 있습니다.

QR의 웹 주소는 GitHub Pages를 설정한 뒤 사용할 수 있습니다. 설정 전에는 포함된 HTML 도구에 QR의 전체 URL을 붙여넣어 사용하세요. 전송은 외부 ntfy.sh 릴레이를 사용하며, 워치 저장소의 암호화 보관과 페어링 난수의 암호학적 안전성은 보장하지 않습니다. 원본 인증기와 복구 수단을 유지하세요.

개인 서명키는 포함하지 않았습니다. `SHA256SUMS`로 다운로드 파일을 검증할 수 있습니다.
