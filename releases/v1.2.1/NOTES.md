# Redmi Watch 6 TOTP 1.2.1 — Android 계정 동기화

Android 동반 앱에서 계정을 직접 추가·수정하고 **워치로 동기화**합니다. QR은 필요하지 않습니다. 외부 계정 서버나 중계를 사용하지 않습니다. QR 카메라/이미지와 URI 가져오기는 선택 사항입니다.

## 설치

- 워치: `com.vela.rw6totp.release.1.2.1.rpk`, Notify for Xiaomi → 펌웨어 업데이트 → 타사 앱(RPK).
- Android 8.0 이상: `rw6-totp-android-1.2.1.apk`.
- **Mi Fitness / 중국판 운동건강에 워치를 연결해야 합니다. Notify 단독 연결에서는 동기화할 수 없습니다.** 최초 기기 통신 권한을 허용하세요.
- Android에서 계정 직접 추가 → 휴대폰에 저장 → 워치로 동기화. 워치 TOTP 수신 화면을 자동으로 엽니다. 자동 실행되지 않으면 워치에서 **+ Phone**을 열고 다시 동기화하세요. 수신 화면에서는 동기화 요청을 자동 저장합니다.
- 완료 응답 후 워치 Close → 계정 목록에서 원본 인증기와 코드를 비교하세요.

## 동작

- 휴대폰 계정은 Android Keystore AES-256 / AES-GCM으로 암호화하고 백업·기기 이전에서 제외합니다. 앱 삭제·키 손실 후 복구를 제공하지 않으므로 원본 인증기·복구 코드를 유지하세요.
- APK에는 인터넷 권한이 없고, 워치에는 HTTP/웹소켓 권한이 없습니다. Mi Fitness 자체 서비스의 일반 네트워크 정책은 변경하지 않습니다.
- 저장 성공 응답 후에만 완료를 표시합니다. 수신 준비 확인·요청 ID·타임아웃·중복 방지·오류 표시를 포함합니다.
- 동일 항목을 수정·재동기화하면 갱신합니다. 워치의 수동 계정은 유지합니다. **휴대폰 삭제는 워치에 전파하지 않으며**, 워치에서 Edit → Delete → Confirm으로 삭제합니다.
- 최대 50개 계정, SHA1/256/512, 6/8자리, 5–3600초를 지원합니다.
- 직접 워치 입력은 **+ Key**에 유지했습니다. `totp-import.html`은 선택 보조 도구이며 동기화에 필요하지 않습니다.
- 기존 앱 ID·서명·워치 저장소 키를 유지했습니다. APK와 RPK의 인증서도 일치합니다. 이전 앱을 삭제하지 말고 업데이트하세요.

## 검증과 제한

워치/표준 OTP/저장소/RPK 회귀 54개, Android 입력/전송/암호화 17개, 오프라인 브라우저 1개가 통과했습니다. 실제 Android 생성 패킷→워치 저장→RFC OTP→항목 갱신, 컴파일된 세 워치 화면과 수신·저장·응답, APK/RPK 서명·식별자·권한·체크섬도 확인했습니다. Android Lint는 오류 0개이며 한국어 문자열 번역 리소스 관련 경고가 남아 있습니다.

**Redmi Watch 6 중국판 / 펌웨어 3.100.043와 실제 Android·Mi Fitness 사이의 Bluetooth 왕복 및 원격 실행, 카메라·Keystore·터치 동작은 실기기 검증하지 못했습니다.** Mi Fitness의 해당 버전이 XMS 서비스를 제공해야 합니다. 자동 검사 통과가 이 조합의 실기기 호환성을 입증하지는 않습니다.

Android 통신은 MIT 공개 XMS 1.4 Binder 규약 소스로 구현했습니다. Xiaomi 바이너리 SDK나 OronBox 서비스는 포함하지 않습니다. 라이선스 전문은 APK assets와 `THIRD_PARTY_NOTICES.txt`에 포함했습니다.

이번 패치는 원격 CI의 Android 초기화 기본값에서 더 이상 배포되지 않는 구형 tools 패키지 설치를 제외합니다. 필요한 SDK 35 / Build-Tools 35.0.0은 명시적으로 설치합니다. 1.2.0 태그는 보존하며 동기화 기능 자체는 동일합니다.
