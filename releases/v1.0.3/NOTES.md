## 워치 화면의 한글·기호 깨짐 수정

설치 파일: **com.vela.rw6totp.release.1.0.3.rpk** (versionCode 4)

중국판 Redmi Watch 6에서 한글이 깨지는 사용자 보고에 따라 워치 UI를 ASCII 영어로 변경했습니다. 앱은 기본 워치 폰트를 사용하며 별도 한글 폰트를 포함하지 않습니다.

- 앱 이름, 메인/QR 화면, 버튼, 등록 상태와 오류 메시지 전체를 영어로 변경
- 화살표·가위표·가운뎃점 등 폰트에 없을 수 있는 기호를 Up / Down / Delete / 슬래시로 교체
- 한글 계정 이름은 화면에서 ASCII 부분을 사용하고 없으면 Account N으로 표시. 저장된 원래 이름과 인증키는 보존
- 영문 메타데이터가 계정 이름과 겹치지 않도록 카드 폭 조정
- 등록 웹 도구의 안내도 새 워치 버튼명인 + QR Add / Check와 일치하도록 수정

검증: 단위·패키지·컴파일된 화면 검사 41개와 Chromium 웹 테스트 1개 통과. 실제 배포 RPK의 앱 시작과 화면 바인딩, ASCII 문자 사용, 기존 계정 보존, 서명·패키지/파일 해시·ZIP CRC를 확인했습니다. 실제 워치에서의 글리프·레이아웃은 업데이트 후 확인이 필요합니다.

기존 앱을 삭제하지 않고 Notify for Xiaomi의 **펌웨어 업데이트 → 타사 앱(RPK)**에서 업데이트하세요. 앱 식별자·서명·저장소 키를 유지했습니다. 개인 서명키는 포함하지 않습니다.
