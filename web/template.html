TOTP 오프라인 등록 도우미

기존 인증기의 OTP QR 이미지 또는 otpauth URI에서 워치에 입력할 값을 확인합니다. 이미지 읽기와 변환은 이 브라우저 안에서 실행됩니다. 이 파일은 다운로드한 뒤 인터넷 연결 없이 사용할 수 있습니다.

아래 버튼을 누르면 인증키가 화면에 표시됩니다. 다른 사람이 화면을 보지 않는 곳에서 작업하고, 등록이 끝나면 입력을 지우세요. 원본 인증기와 복구 코드를 유지하세요.

워치에서 [+ Add]를 누르고 표시된 순서대로 입력하세요.

등록 방법과 지원 범위

워치의 [+ Add]에서 Secret → Name → Period → Review 순서로 입력하고 Save를 누릅니다. Secret의 공백은 건너뛰고 영문 A–Z와 숫자 2–7만 입력하세요. Name은 선택 사항이며 영문/숫자로 입력합니다. Period를 바꾸려면 워치에서 Clear를 누른 뒤 새 숫자를 입력합니다. Review에서 Hash와 Digits를 아래 정보와 일치시킵니다. 저장 후 원본 인증기와 코드가 같은지 확인하세요.

이 도구는 워치에 자동 전송하지 않습니다. Redmi Watch 6의 공개 API에는 브라우저에서 직접 쓸 수 있는 BLE 수신 기능이 없으며, 워치 QR을 휴대폰으로 읽는 것만으로 반대 방향 전송이 생기지는 않습니다. 기존 GitHub Pages 링크와 ntfy 중계는 현재 등록 경로에서 제거했습니다. Google Authenticator의 otpauth-migration과 암호화된 백업 형식은 지원하지 않습니다. 워치 키 입력 한도는 256자입니다. 계정은 워치의 일반 로컬 저장소에 보관됩니다.
