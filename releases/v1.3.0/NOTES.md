# RW6 TOTP 동기화 1.3.0

## 동기화 응답 유실 수정

이전 버전은 동기화 시작 시 이미 열린 워치 수신 화면을 다시 실행했고, 이전 페이지의 종료 처리가 새 페이지의 interconnect 수신 핸들러까지 덮어쓸 수 있었습니다. 1.2.1의 실제 컴파일된 RPK에서 페이지 실행·종료가 겹칠 때 준비 응답이 끊기는 결함을 재현하고 수정했습니다.

- 현재 화면에 먼저 준비 응답을 요청하고, 응답이 없을 때만 원격 실행을 시도합니다.
- 이전 페이지는 자신의 수신 처리만 비활성화하며 새 화면의 핸들러를 지우지 않습니다.
- JSON·data 객체/문자열 래퍼·UTF-8 수신 형식을 제한된 크기와 깊이 내에서 처리합니다.
- 초기 준비 확인의 전송 실패가 원격 실행과 재시도를 막지 않도록 했습니다.
- 워치에는 데이터 수신 여부와 준비 응답 전송 성공/오류를 표시합니다. 저장 성공은 실제 저장 응답 후에만 표시합니다.

## Android 화면 변경

제목을 **RW6 TOTP 동기화**로 변경하고 그 아래에 **TOTP 목록 / 계정 추가 / 수정 / 동기화**만 배치했습니다. 연결은 동기화 버튼이 처리하며, 진행 상태는 버튼에, 완료·오류는 일시 알림으로 표시합니다. 긴 설명과 별도 재연결 버튼을 제거했습니다.

QR 스캔·카메라·이미지/URI 가져오기·웹 도우미와 관련 실행 라이브러리·카메라 권한을 제거했습니다. 이번 릴리즈에는 HTML 도우미를 배포하지 않습니다.

## 업데이트

1. `com.vela.rw6totp.release.1.3.0.rpk`를 Notify의 펌웨어 업데이트 → 타사 앱(RPK)에서 업데이트합니다.
2. `rw6-totp-android-1.3.0.apk`로 Android 앱을 업데이트합니다. 기존 앱을 삭제하지 마세요.
3. Mi Fitness / 중국판 운동건강에 워치가 연결된 상태에서 TOTP → **+ Phone**을 열고 Android의 **동기화**를 누릅니다.

기존 APK/RPK 인증서·앱 식별자·Android 암호화 목록/키 별칭·워치 저장소·안정적인 syncId를 유지합니다. 계정 수정은 같은 항목을 갱신하며 휴대폰 삭제를 워치에 전파하지 않습니다. 원본 인증기와 복구 코드를 유지하세요.

## 검증

워치·암호·저장소·컴파일된 화면·수신 수명 회귀 60개와 Java 21개(수신 프로토콜, 암호화, Android 화면 실행 및 입력 창 포함)가 통과했습니다. 기존 RPK는 수신 수명 충돌 검사에서 실패하고 새 RPK는 통과합니다. 실제 Android 생성 패킷 → 워치 저장 → RFC OTP → 갱신, APK/RPK 서명 일치 및 인터넷·카메라 권한 부재를 검증했습니다. Android Lint는 오류 0개입니다.

실제 Redmi Watch 6 중국판 / 펌웨어 3.100.043의 Bluetooth 왕복과 네이티브 UI 동작은 이 클라우드에서 직접 확인하지 못했습니다. 재현한 코드 결함의 수정이며, 사용자 기기에서 최종 동기화 확인이 필요합니다. XMS 서비스가 없는 Mi Fitness 버전이나 Notify 단독 연결에서는 동기화할 수 없습니다.
